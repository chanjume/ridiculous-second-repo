Vultures for Hire: we lease vultures to highway departments — one bird strips a deer carcass in under an hour, so counties pay per carcass instead of dispatching a truck crew.

`main.ts` writes a single 155-character sentence to `/output/entry.txt`, pitching a bizarre startup idea that sounds ridiculous at first glance but makes sense as a real business.

## Run it

```sh
node main.ts
```
